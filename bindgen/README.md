# SDL Binding Generation

This directory contains the SDL-specific input and policy for generating
`klaseca/sdl-sys`. The reusable C-to-MoonBit implementation is provided by the
external `moonbit-bindgen` development dependency.

## Setup

From the repository root, initialize the SDL submodule and install the pinned
generator dependency:

```sh
git submodule update --init --recursive
npm install
```

Run the generator after updating SDL or changing the binding policy:

```sh
npm run bindgen
```

The generator reads headers from `externals/SDL/include/SDL3` and writes
MoonBit and C output to `modules/sdl-sys/src`.

## Local Configuration

`bindgen_sdl_sys.ts` connects SDL's declaration syntax to
`moonbit-bindgen/c`, selects the emitted file names and C header includes, and
runs the generation pipeline.

`sdl_sys.config.ts` describes which SDL declarations are part of the binding
and their SDL-specific ownership, lifetime, nullable parameter, naming, and
type policies. Generation is explicit: unsupported configured declarations
fail instead of being silently omitted.

## Generated and Manual Files

Generated files have the `_gen` suffix. Do not edit them by hand. The manifest
at `modules/sdl-sys/src/.bindgen.json` records files owned by the generator so
that stale generated output can be removed without affecting manual code.

Callback trampolines that require manual MoonBit closure lifetime management
remain beside the generated output without the `_gen` suffix. Pointer helpers,
C-string conversion, value-struct accessors, and other generic binding support
are generated by `moonbit-bindgen`.

Generated MoonBit names remove the SDL prefix and use lower snake case. C stub
symbols retain the `moonbit_sdl_` prefix used by the corresponding MoonBit
extern declarations.
